# JobTrap – AI-Powered Job Scam Detection

JobTrap is a cybersecurity web application that helps users identify potential job scams by analyzing job descriptions and recruiter messages for suspicious patterns.

### Features
- Job offer and recruiter message analysis
- AI-assisted and rule-based detection
- Highlights potential scam indicators
- Supports document or image scanning (if implemented)

### Tech Stack
- Frontend: React, Vite
- Backend: Node.js, Express.js
- AI: Google Gemini API
- Language: JavaScript

### Future Improvements
- More accurate scam detection
- Employer verification
- Improved document scanning

### Disclaimer
JobTrap is an experimental project. Results may be inaccurate, so users should independently verify employers and job offers.
